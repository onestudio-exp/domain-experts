# GCC / MENA B2B Revenue — Glossary

## Buyer types (anchors)

- **Family conglomerate** — UAE / KSA private-family-owned multi-business holding (e.g., Al Futtaim, MAF, Olayan). Decision rests with the family principal; procurement is a process, not a decision-maker.
- **Government-linked** — KSA gov't / PIF-portfolio / ADNOC / STC / Aramco — process-heavy, vendor-registration-gated, long cycles.
- **MENA scale-up** — venture-backed SaaS / fintech / e-commerce — Western-style buying patterns mixed with local nuances.
- **SMB merchant** — owner-operator small business. Salla / Zid / Shopify reality.

## Channels

- **WhatsApp Business** — closes more B2B deals in GCC than email. Cloud API direct or via BSP (Wati, Unifonic, Twilio).
- **LinkedIn** — GCC has highest LinkedIn-per-capita in the Arab world; connection acceptance is high; cold InMail conversion lags US.
- **Email** — used for procurement / formal docs / when CC'ing multiple stakeholders. Cold email open-rates lower than US baseline.
- **Face-to-face** — still material: GITEX (UAE), LEAP (KSA), industry events. A coffee in Riyadh closes deals.

## Sales frameworks

- **MEDDPICC** — Metrics, Economic Buyer, Decision Criteria, Decision Process, Paper Process, Identify Pain, Champion, Competition.
- **SPIN** — Situation, Problem, Implication, Need-payoff.
- **Challenger** — Teach / Tailor / Take Control approach.
- **AARRR** — Acquisition / Activation / Retention / Referral / Revenue.

## Cycle windows

- **Ramadan** — pipeline slows ~50%; meetings shift to evening; do not push closes in last 10 days.
- **Eid Al-Fitr** — 1-week dead zone; resume cadence after.
- **Eid Al-Adha + Hajj** — KSA-specific 2-week dead zone.
- **Summer executive exodus** — July–August; GCC C-suite often in Europe; meeting cancellation rate spikes.
- **GITEX season** — Oct (UAE) — outbound conversion lifts on the runway; event-attended deals close in Q4.
- **LEAP season** — Mar (KSA) — same dynamic, KSA-anchored.

## Reality-audit gap tiers

- **Match** — code does what claim says.
- **Partial** — code does some but not all.
- **Mismatch** — code does something materially different.
- **Vaporware** — claim with no code reality behind it.

## Decision vocabulary

- **Go** — clear position; GCC/MENA reality supports.
- **Go-with-conditions** — proceed after named conditions.
- **No-Go** — would fail in region.
- **Reframe** — wrong question.

## Out-of-scope handoff receivers

- **Engineering** — for code, architecture, schema, infra.
- **Visual / UX** — for layouts, colors, motion, micro-interactions.
- **Legal counsel** — for binding regulatory interpretation.
- **CFO / finance** — for spreadsheet builds, sensitivity models.
