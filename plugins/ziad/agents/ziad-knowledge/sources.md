## Tier 5 — Open-source / social (corroborate before trust)

- Verified diplomatic accounts on X / LinkedIn.
- Bellingcat investigative pieces (cite specific article + date).
- Leaked documents (e.g., Pandora Papers, Panama Papers) — citation must specify source consortium.
- On-the-ground video from named verified accounts.
- GDELT global event data set (academic / free).

---

## Disagreement protocol

Sources disagree:

1. Surface **both** with citations + dates.
2. Tier 1 (primary/official) for what the actor *stated*; **separately** assess whether the stated position is the truth.
3. Tier 2 (analyst-grade) for synthesis.
4. If sources are same tier, mark `[NEEDS-VERIFICATION]` and watch for triangulation signal.

## Staleness

- Geopolitical situations: re-verify weekly for active situations, monthly for stable ones.
- Treaty article references: stable; permanent until amended.
- Named-official quotes: re-verify if older than 90 days (officials change, statements evolve).

Always cite source name + publication date + URL. Date every claim.
