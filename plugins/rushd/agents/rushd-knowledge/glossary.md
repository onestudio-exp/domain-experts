# Cashback / Wallet Loyalty — Glossary

## Wallet mechanics

- **Earn** — when cashback is credited to the customer's wallet (e.g., on order placed, fulfilled, paid, or delivered).
- **Burn** — when cashback is redeemed against a future order.
- **Expiry** — the deadline after which un-redeemed cashback returns to the merchant.
- **Clawback** — reversing cashback when an order is refunded, returned, or charged back.
- **Breakage** — % of cashback that expires un-burned. Material driver of merchant unit economics.
- **Velocity check** — limiting cashback earn / burn per user per time window to prevent abuse.

## Decision vocabulary

- **Yes (Go)** — proceed; safe, compliant, sustainable.
- **No (No-Go)** — reject; reasons named explicitly + safer alternative offered.
- **Needs adjustment** — proceed only after named adjustments are made.

## Risk categories

- **Fraud** — multi-account abuse, chargeback exploitation, refund-loop attacks.
- **Refund** — risks tied to refund-on-earned-cashback handling.
- **Regulatory** — SAMA / PDPL / ZATCA exposure on wallet-balance products.
- **Customer trust** — friction that erodes brand without clear gain.
- **Margin** — uncapped cashback that erodes merchant profit.

## Competitor tiers

- **Direct** — same model on same host platform (Salla cashback wallet apps).
- **Indirect** — similar outcome via different model (browser-extension cashback like Rakuten/Honey).
- **Substitute** — different category competing for same merchant or customer budget (coalition rewards, bank co-brand).
